      Welcome to ChoreCade!

      🎮 Games That Do Real Work

      ChoreCade turns boring digital chores into fun arcade games. Every move you make in a game performs a real action on your files, emails, or code.

      Highlighted: The main description area

      📋 The Game Cabinets

      Each card represents a different chore cabinet. Click "Play" to start the game, or "Calm mode" for a keyboard-friendly alternative.

      Highlighted: The list of available games

      📊 Progress Tracking

      Each cabinet shows how many items remain and your progress. The "done" section summarizes what you've accomplished.

      Highlighted: Progress meters and completion status

      📝 The Ledger

      Every real change is recorded here. You can undo any action by clicking the Undo button. Nothing is ever permanently deleted!

      Highlighted: The ledger showing all changes

      🔗 Google Integration

      Sign in with Google to work with your real Gmail inbox and Google Drive. Your data stays safe and every action is undoable.

      Highlighted: Google sign-in button area

      Inbox Invaders: Space shooter that archives emails by sender
      Folder Frenzy: Courier game that sorts files into folders
      Receipt Rush: RPG that categorizes expenses
      Lint Dungeon: Castle crawl that fixes code lint errors
